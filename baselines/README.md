# Baselines

This directory contains maintained comparison methods that are useful for evaluating the proposed system.

`knn/` preserves the earlier Wi-Fi, magnetic, hybrid KNN, and Kalman-smoothed proof-of-concept. Its original generated figures and notes are retained for provenance. Before using KNN values in the current paper, rerun the baseline through the canonical dataset and evaluation pipeline and record the results under `experiments/results/`.
