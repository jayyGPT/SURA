# Literature index

## Cluster 1 — Wi-Fi and magnetic spatial localization

Fingerprinting, magnetic sequence models, device heterogeneity, GNN positioning, and the MagWi dataset. Use this cluster for the environment-model and magnetic-measurement related-work sections.

## Cluster 2 — Wi-Fi, magnetic, IMU, and PDR fusion

The most directly relevant group for the proposed system. It covers sensor-fusion frameworks, Wi-Fi-aided PDR, magnetic/PDR integration, heading calibration, and probabilistic multi-sensor positioning.

## Cluster 3 — advanced and adjacent methods

Graph methods, cross-building/network tracking, patent material, and additional positioning systems.

## Citation workflow

1. Read and verify the actual paper rather than relying only on its filename.
2. Add a complete BibTeX entry to `paper/Ref.bib`.
3. Tie each substantive manuscript claim to the source that supports it.
4. Record comparison-protocol differences before placing literature values beside project results.
