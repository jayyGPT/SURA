# Historical generated dataset artifacts

These files were uploaded beside the original MagWi source data but are derived outputs from
older experiments. They were moved here so `data/raw/magwi/` contains only the original
`Magnetic field dataset/` and `WiFi dataset/` trees.

Contents include earlier fused CSVs, simulated Wi-Fi data, KNN/fusion metrics, merged datasets,
and generated figures. They are retained for provenance but are not canonical training inputs
for the current code.
