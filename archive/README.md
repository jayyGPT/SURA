# Archive

This directory preserves historical implementations, generated artifacts, old publication workspaces, and scratch material from the development of SURA.

Nothing under `archive/` is canonical active code. Do not import archived modules into new workflows and do not cite archived metrics as current results without reproducing them from the active code.

- `model_snapshots/`: curated standalone reproductions from the previous `Models (Read Only)` directory.
- `legacy_experiments/`: the former testing and benchmarking sandbox, including failed and intermediate models.
- `legacy_publication/`: old manuscripts, build outputs, and revision artifacts.
- `scratch/`: temporary scripts, generated data, and dataset-analysis workspace.
